# M2 報告：S1 全身圖與 S2 部件圖流程（RC01、RC02）

日期：2026-10-04

## 流程（最終版）

```
S1  原圖＋文字 → edit（只改指定內容、姿勢不動）→ apose（正面立正 A-pose）→ master_front
    master_front → camera-angle LoRA → master_45（左前方 45°，看得到機甲正面與它自己的右側）
框選 mechpipe boxes：依 A-pose 比例預框 18 個部位 → 瀏覽器調整
S2  頭、手臂、腿：從 master_45 以文字抽取整件 → 依框垂直比例切出細分段 → 補完切口（維持 45°）
    軀幹組：master_front 刪雙臂 → 以框塗除頭/腿/肩 → 裁切軀幹 → 補完 → 切出胸腰/腰髖 → 補完 → 轉 45°
    每步自動 QC，不過就換種子重試；mechpipe deliver 收集通過的 45° 圖
```

指令與參數見 `CLAUDE.md`、`mech-pipeline-spec.md` 第 5 節；`mechpipe/stages.py` 的 `S2Run` 有每一步的理由。

## 嘗試過的做法與結論

| 問題 | 試過 | 結論 |
|---|---|---|
| 「參考圖＋文字」產生全新機甲 | 2511 三張參考圖 | 照抄參考圖（只有一張是正面全身時更明顯） |
| | Qwen-Image-2512 文生圖 | 能做新設計，但 4 張雷同、偏鋼彈；保留為 `design` 模式 |
| 改色＋轉 A-pose 一步完成 | 2511 `variant` | 比例與機械細節走樣 |
| | 先改色（姿勢不動）再轉 A-pose（原圖當第二參考） | 忠實，採用；定稿模式會把原圖的舊色帶回，維持草稿模式 |
| 部件抽取 | ObjectExtraction LoRA（裁切＋單色遮罩） | 抽不出或補出整台 |
| | 在全身圖畫框 / 只保留框內 | 大部件重畫整台、構圖照抄 |
| | 整張圖＋文字 | 頭、整隻手臂、整條腿可用；細分部位都畫成整肢 |
| | 從乾淨整件依框比例切段＋補完 | 細分部位可用；帶參考圖反而重畫整件 |
| 軀幹 | 文字抽取 | 帶手臂，或把頭腿補回 |
| | 刪雙臂（可靠）＋刪頭（可靠）＋刪大腿（不穩） | 約一半成功 |
| | 框塗除＋裁切＋補完 | 約一半成功；失敗時補成整台機器人，QC 難以判斷 |
| 轉 45° | 文字提示 | 細長件不會倒，但扁平件（手臂、肩）轉不動 |
| | camera-angle LoRA（單一部件） | 轉得動，但細長件會倒、壓扁 |
| | fal Multiple-Angles LoRA | front-left / front-right 結果相同，方向錯 |
| | camera-angle LoRA 轉整台 master，再抽部件 | 方向正確、比例穩定，採用（頭、四肢） |

## 自動 QC（`mechpipe/qc.py`）

純白背景、未被畫面切到、無地面陰影、長寬比、不是整台機甲、不是又畫回整件、沒有 master 以外的新顏色（抓重新設計）、軀幹組 45° 有轉。抓不到：多長出的手腳（軀幹組）、部位左右、細節走樣。

## 已知限制

- 軀幹組（`TORSO_FULL`、`CHEST_WAIST`、`WAIST_HIP`）成功率最低，交付時每條鏈各一張候選，manifest 標記 `manual_pick`，需人工挑選。
- 腳踝＋腳掌、整條腿偶爾被畫面切到（QC 會重試，但不一定救得回）。
- 草稿模式（Lightning）偶爾會加上原本沒有的編號字樣。
- 框由使用者在正面 master 上標；RC02 的框由 Claude 目視設定。
